# Changelog

## Unreleased

Initial public portfolio candidate, built incrementally with the original Git
history retained. No release tag has been published.

- Simple Scan → Review suggested folders → Organize workflow with one final
  move confirmation and a prominent Undo Last action.
- Explainable offline filename rules, study subjects, custom categories, and
  persistent rule settings; advanced controls stay collapsed by default.
- Explicit destinations, high-confidence selection, collision protection,
  incomplete/locked-file handling, and directory exclusion.
- SQLite operation journal, migration support, content/identity verification,
  and safe individual, historical, partial, and interrupted-operation undo.
- Disposable demo data, automated Python/HTTP/filesystem tests, reproducible
  Playwright checks, and real desktop/mobile screenshots.
- Public-repository preparation: security/privacy guidance, stronger ignore
  rules, and a Windows Python regression workflow with pinned official actions.

The original extension CLI remains available. The legacy Streamlit frontend is
experimental and outside the supported release surface.
